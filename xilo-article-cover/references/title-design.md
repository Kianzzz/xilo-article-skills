# 封面标题设计

## 核心门禁

每套标题同时回答：

1. 文章取得了什么可验证结果，或解决了什么明确问题；
2. 读者看完能获得什么。

结果必须来自文章。没有数字或成果时，用“明确对象 + 获得感 + 认知反转”，不编收益、效率或版本状态。

## 三秒可读性与点击价值

每个候选脱离正文后都必须在三秒内说清三件事：

1. `具体对象`：什么工具、任务、内容类型或产品；
2. `具体产物`：读者将学会做出什么，或解决什么明确问题；
3. `点击理由`：教程、方法、公开资料、可信社会证明或有效好奇点。

- “混剪、效率、流程、跑通、搞定、玩法”等泛化词不能单独承担主题或结果；必须和具体对象、具体产物放在一起。
- 不把步骤数、素材准备、环境配置等前置成本放在标题主位，除非它们本身就是文章要解决的核心问题。先让读者看到收益，再决定是否补充成本或边界。
- 痛点必须能让目标读者第一眼识别为自己的具体任务；不能用相邻概念制造伪痛点，例如把一般自动剪辑写成节奏卡点。
- 悬念必须仍然交代内容价值。优先问“如何做出来、为什么能做到、关键方法是什么”，避免只问“会发生什么”或故意隐藏产物。
- 价值放大词必须有正文依据。`全公开、提示词公开、保姆级攻略`分别要求正文确实交付完整方法、提示词或足够细的可执行步骤；社会证明必须有可核验数量或明确事实，不把“有人问”改写成“几千人追问”。
- 候选筛选时，先淘汰需要解释才能成立的标题，再比较吸引力。作者熟悉的行业简称不等于读者能立刻理解。

## 五条候选路线

五套候选必须真正不同，默认覆盖：

1. `明确怎么做`：具体对象 + 如何得到具体产物；
2. `教程价值`：明确教程对象 + 完整、公开或保姆级等有依据的价值承诺；
3. `结果获得`：具体产物 + 读者可获得的方法；
4. `方法悬念`：核心对象不隐藏，用“如何做出来/关键是什么”制造好奇；
5. `可信放大`：有证据的社会证明、公开程度或稀缺资料 + 明确教程对象。

只有文章确实提供模板、源码、完整流程或公开资料时，才能使用“附模板、开源、全公开、完整流程”等词。

## 封面文字结构

- 主标题通常控制在 8–16 个中文视觉字符，最多两行；英文产品名视为不可拆单元。
- 主标题必须包含文章核心对象或独有关键词，脱离正文仍能看懂主题。
- 小标签通常 2–6 字，仅补充内容类型或获得感，例如 `保姆教程`、`完整流程`；主标题已经表达时不重复添加。
- 标题与小标签职责分开：标题说明“讲什么”，小标签说明“能拿到什么”。
- 不写完整长句、口号、迷你目录或步骤清单。
- 不为了押韵或悬念隐藏核心对象。

## 断行规则

- 每个候选必须给出明确断行，不把断行交给图像模型随机决定。
- 优先按语义单元断行，不拆开产品名、数字单位和固定短语。
- 两行长度不必相同，但核心词应成为更大的一行或更大的字级。
- 所有文字横平竖直；不通过倾斜、旋转或透视变形制造冲击力。

## 方形辅图

方形辅图不能承载完整横版标题。二选一：

- 一个主题相关的 IP 动作，不加字；
- 从已确认标题提炼 2–4 个字的核心短语。

不得另造第二个标题。

## 输出格式

```text
方案 1｜<路线名>
主标题：<逐字标题>
断行：<第一行> / <第二行>
小标签：<2–6 字或无>
结果：<文章证据>
获得感：<读者收益>
适用：<画幅或风格说明>
短版备用：<必要时填写，否则无>
```

五套之后推荐一套并解释理由，等待用户确认。
