# 平台画幅与交付

## 公众号文章封面

- 主封面：原生 `2.35:1`，建议交付 `2350×1000`。
- 辅封面：原生 `1:1`，建议交付 `1200×1200`。
- 每个风格交付两张最终图，再生成一张组合预览。
- 组合预览只用于审阅，不作为上传文件。
- 主图和方图共享标题、主题、IP、证据和风格，但必须分别构图。

组合预览：

```bash
python3 scripts/build_wechat_preview.py MAIN.png SQUARE.png PREVIEW.png
```

## X Articles

- 生成原生 `5:2`，建议交付 `2500×1000`。
- 这是本 Skill 约定的比例，不宣称为 X 官方发布规格。
- X Articles 封面不是 X 个人主页横幅，也不是普通帖子配图。

## 视频封面

- 首轮竖版：原生 `3:4`，建议交付 `1080×1440`。
- 用户确认横版后：原生 `16:9`，建议 `1920×1080`；原生 `4:3`，建议 `1440×1080`。
- 不提供 YouTube Shorts `9:16` 分支。
- 同一方案跨画幅保持标题、IP、主证据、色彩和风格，独立重构位置与尺度。

## 计数

假设选择 `N` 种风格：

- 公众号：`2N` 张最终图 + `N` 张组合预览。
- X Articles：`N` 张最终图。
- 视频首轮：`N` 张 3:4 最终图。
- 视频横版扩展：额外 `2N` 张最终图。

生成前必须把实际数量告诉用户。
