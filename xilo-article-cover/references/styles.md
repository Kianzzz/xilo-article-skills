# 封面八种样式合同

## 全局参考图职责

- 角色身份：读取 `character.md`；默认小水獭，或采用用户明确提供的完整角色设定。
- 用户提供风格参考图时：锁定媒介、色系、视觉密度和必要结构特征；镜头、动作、动线、文字分区和对象位置由当次主题重新设计。各节的位置描述是构图候选，不是固定坐标；复用版式须有用户明确要求。不得复制旧标题、主题对象或小标签，也不得把 3:4 参考图当作其他画幅的裁切源。
- 色值以当前草木绿 `#28A85B` 及其延伸色为准；参考图中的人物由当前角色完整替换。深绿背景使用 `#14532D`，中绿 `#73D994`、浅绿 `#C8F2D5`、结构深绿 `#16733D`；真实品牌素材保留原色。
- 文章内容决定当次主证据、角色动作、漂浮元素和主题道具。不得把剪刀、胶片、商品卡、终端或时间线变成所有主题的固定装饰。
- 所有可读文字横平竖直、基线平直，不倾斜、不旋转、不弧排、不做透视字。动势来自动作、镜头、前后景和对象路径。
- IP 允许夸张，但气质必须呆萌、好奇或兴奋；禁止压低内眉、横眉、怒视、咬牙、攻击姿态和成人化。
- `#28A85B` 是默认主题绿。背景颜色必须服从具体样式合同，不能擅自把纯白样式改成米白，也不能把绿色样式改成白底。

## 1. 纯白高透视破框

Slug：`pure-white-break-frame`

### 风格骨架

- 纯白 `#FFFFFF` 主背景，巨大两行标题和紧凑小标签的位置按当次构图安排。
- 有一个明确的矩形场景入口；IP 的身体部分留在框内，手、脚或主题对象跨出框外冲向镜头。
- 使用强制透视制造近大远小：最靠近镜头的手、鞋或对象最大，头部次之，身体与工作空间最远。
- 场景入口内展示一个简化、真实可理解的主题环境；四周只漂浮与文章直接相关的对象。

### 内容适配

- 动作每次根据主题重新设计，例如抓住失控对象、递出成果、从流程窗口冲出、托起工具或踢开障碍。
- 漂浮元素同样由主题决定，最多 4–6 个；不固定使用胶片、剪刀或鼠标。
- 表情可惊喜、慌张、兴奋或好奇，使用软眉、角色设定中的眼睛、小圆嘴/柔和张嘴、腮红或轻微汗滴。

### 画幅响应

- 竖版可采用上字下画、上画下字或侧部留字；保留从场景框向前冲出的纵深。
- 横版可把标题与场景分居左右，前景肢体或对象仍明显跨出场景框。
- 方图只保留一个高透视动作和一个主对象；文字缩为 2–4 字或不加字。

### 避免

米白或灰白背景、人物平站框前、人物全身都在框外、透视不明显、凶狠战斗脸、通用星星、无关漂浮装饰、歪斜标题。

## 2. 蜡笔主题剪贴

Slug：`crayon-scrapbook`

### 风格骨架

- 品牌绿色蜡笔满涂背景，保留明显但干净的手工涂抹笔触。
- 标题是黑色粗蜡笔方字，周围带不规则暖白剪纸底或白边，所有行保持水平。
- 一个白边全身 IP 位于主视觉区，与 4–6 个白边剪纸主题图标形成清楚的主次和动作关系。
- 整体像儿童手帐或手工剪贴簿，但信息层级仍像商业封面。

### 内容适配

- IP 姿势解释文章主题，可指向、展示、抱住、检查或操作主题对象。
- 四周小元素必须从文章中提取；不使用星星、爱心、彩虹等泛化可爱填充。
- 小元素比人物和标题更小，不能平均铺满画面。

### 画幅响应

- 横版可采用“标题一侧、IP与剪贴元素另一侧”的稀疏手帐布局。
- 方图减少到 2–3 个主题图标，避免小元素过密。

### 避免

通用星星、光滑矢量图、照片写实、复杂 UI、细小可读文字、蜡笔底变成均匀纯色色块、标题歪斜。

## 3. 电商素材检查

Slug：`material-inspection`

### 风格骨架

- 纯白或接近纯白背景，巨大绿色两行标题，小标签紧凑靠近标题；文字区域按检查动作安排。
- IP 使用放大镜检查一个主证据；放大镜必须对准主题细节，并产生真实的局部放大关系。
- 下方或一侧放置一个简化工作台、检查台或结果面板；2–4 个相关资料卡沿明确路径进入或离开主证据。
- 绿色虚线箭头只表达一个清楚的检查因果链，不绕成装饰圆环。

### 内容适配

- “素材”按文章主题解释，可变成页面、代码片段、数据卡、文档、商品、音频或流程节点。
- IP 的另一只手必须正在拿取、放置、标记或比较对象，不能只是举着放大镜摆拍。
- 漂浮资料卡和动作物品必须与当次主题对应。

### 画幅响应

- 横版可把“待检查对象 → 放大镜/IP → 结果面板”横向排列，也可用俯视纵深组织同一检查关系。
- 方图只保留放大镜、IP和一个证据卡，不生成完整工作台。

### 避免

泛化报纸、无关文件、假装可读的真实 UI、多个放大镜、没有被放大的细节、人物动作与对象无接触、米白底。

## 4. 纯白马赛克聚焦

Slug：`white-mosaic-focus`

### 风格骨架

- 大面积纯白，搭配浅灰和浅绿的简化场景；整体明亮，不能深沉。
- 使用高机位俯拍，IP 从工作场景中抬头仰视镜头。
- 只有一个矩形或方形聚焦框内的局部清晰；框外人物、桌面和主题环境使用大面积浅色马赛克与景深模糊。
- 场景必须是与角色设定一致的简化手绘世界，不使用写实黑暗房间。

### 内容适配

- 清晰区域根据主题选择脸、动作手或关键对象，但只能有一个清晰焦点。
- 框外仍要看出文章场景的大关系，只是不可读、不可抢焦点。
- 标题可置顶或置底，但不得覆盖聚焦框和仰视关系。

### 画幅响应

- 横版扩大模糊场景，清晰框放在视觉黄金点；不要简单裁掉上下标题。
- 方图以俯拍场景和清晰框为主，标题缩为短语或不加字。

### 避免

全图清晰、多个清晰窗口、深色压抑场景、暖米白大底、IP平视或俯视、随机数字噪点、像素化标题。

## 5. 深绿手绘

Slug：`dark-green-naive-poster`

### 风格骨架

- 深森林绿满版背景，保留细腻纸面颗粒；不能改成白底。
- 奶油黄、略显笨拙的手绘粗体大字水平排列并占据主视觉，位置按当次构图安排。
- 小标签使用黄色圆角对话框或胶囊。
- 较小的 IP 从一堆主题对象中探出或被对象包围，形成“事情很多但仍可爱”的叙事；场景与大字错开。

### 内容适配

- 对象堆必须来自文章主题，并形成一个可理解的困境、工作量或成果堆。
- IP 表情偏茫然、惊讶或努力，不使用抓狂怒脸。
- 奶油黄是主要文字色，品牌亮绿只用于小型连接点。

### 画幅响应

- 横版可把大字放左/上，场景扩展成右侧横向对象堆，也可交换两者分区。
- 方图保留大字与一个紧凑底部场景，避免把人物缩得过小。

### 避免

白色主背景、光滑现代字体、矢量企业感、角色占满全画面、对象堆与主题无关、黄色荧光发亮、歪字。

## 6. 绿色对话框漫画

Slug：`green-speech-bubble-comic`

### 风格骨架

- `#28A85B` 绿色漫画网点背景，黑色粗边和少量黄色强调线。
- 巨型白色对话框形成清楚的标题区，可位于顶部、下方或一侧；标题黑色、超粗、水平基线平直。
- 画面包含 2–3 个黑边证据分镜，分别表达输入、处理和结果，不塞完整流程说明。
- 前景一个大 IP 指向或操作分镜，动作线清楚，角色与分镜发生交互。

### 内容适配

- 分镜内容根据文章重新设计，避免固定商品卡、终端和时间线。
- IP 的手势必须把视线导向最重要的结果分镜。
- 黄色只做警示线、状态卡或小闪光，不改变绿色主背景。

### 画幅响应

- 横版可把对话框与分镜左右展开，IP跨两个区域形成连接。
- 方图减少为 1–2 个分镜，保留对话框轮廓和主动作。

### 避免

黄色主背景、对白框太小、四个以上分镜、随机漫画对白、IP缩在角落、分镜像企业PPT、倾斜标题。

## 7. 绿色复古掌机

Slug：`green-retro-game-console`

### 不可漂移锚点

- 绿色复古掌机是主要视觉载体，屏幕、十字键和功能键清楚可辨；可正视、俯视、侧视或局部特写，不要求外壳正面贴满画布。
- 场景采用 16/24 位像素美术；IP 保留角色设定中的轮廓、眼睛、配色与标志饰物。
- 标题使用可读的像素方字，位置按本轮构图选择；即使机身带透视，文字仍保持水平。
- 屏幕内容与人物动作表达输入、处理或成果的主题关系，不固定为横向跳台和终点旗。

### 构图选择

- 可做俯视操作台：控制键位于近景，IP 从屏幕探出并递交成果，工具 Logo 融入卡匣或操作部件，标题使用独立水平区域。
- 也可做侧向屏幕操作、单个主题关卡或控制区特写；每次按主题选用一种主要空间关系，不把所有方向塞进同一张图。

### 内容适配

- 屏幕对象、操作部件、成果和必要关卡道具从文章主题提取；没有关卡叙事时不添加障碍、奖励或终点旗。
- HUD 只使用图标、色块和不可读短线；禁止额外计数文字、`x00`、随机分数或伪英文。
- 绿色外壳必须是主识别色，屏幕可使用蓝天、深蓝或深绿形成层次。

### 画幅响应

- 竖版按当次动作选择完整机身或俯视操作台，标题可位于屏幕旁、机身信息区或独立下部区域。
- 横版独立设计横向掌机或横向操作台，不拉伸竖版外壳；控制区可以左右分居。
- 方图使用近方形掌机结构，保留屏幕、一个方向键和少量按钮。

### 避免

红色主外壳、写实游戏截图、第二角色、额外HUD文字、过多金币、与文章无关的蘑菇关卡、非像素平滑人物、歪标题。

## 8. 绿色剪纸杂志

Slug：`green-cutout-magazine`

### 风格骨架

- 品牌绿色满版纸张背景，带轻微印刷或纸纹；不能改回蓝色。
- 背景使用超大黄色标题和克制的红色错版投影，标题占画面主要面积并保持水平。
- 一个带粗白边的剪纸 IP 位于前景；主题卡、工具、结果标记以白边杂志贴纸形式与其交互，可分组、串联或环绕。
- 拼贴物之间有前后遮挡，但标题、脸和动作手仍清楚。

### 内容适配

- IP 一手持主题工具或结果卡，另一手托住、连接或展示一组主题素材。
- 贴纸全部来自文章主题，最多 4–6 个；不默认使用剪刀、相机、胶片或终端。
- 小标签采用绿色或白色贴纸，不能比主标题更醒目。

### 画幅响应

- 横版可用超大标题横向铺底，IP与贴纸形成一侧前景群。
- 方图减少贴纸数量，保留大字、IP和一个主题对象。

### 避免

蓝色主背景、贴纸均匀排成图标网格、标题被人物完全遮住、通用星星、无关杂志条码、真人照片、歪斜标题。
