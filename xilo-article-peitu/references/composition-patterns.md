# 构图模式与隐喻设计

## 选择结构

每张图选择一种主结构。

### 输入—处理—输出

适合内容生产、AI 工作流和自动化链路。输入位于一端，核心装置承担处理，输出位于另一端；留白服务主流向。

### 系统局部

适合信息源、过滤器、数据库、渲染器和 Agent 局部。选择 3–5 个关键模块，角色操作其中的关键节点。

### 前后对比

适合混乱与有序、手动与自动、分散与收拢。左右两端承担对比，中部动作负责转换。

### 角色状态

适合用户痛点、创作者状态、信息焦虑和卡点变化。使用 2–4 个超大状态牌、仪表或容器表达连续变化；每个固定角色在整张图中只出现一次，不用重复角色充当多个状态。

### 概念装置

适合内容工厂、信息仓库、脑内黑盒和自动日报。使用一个具备记忆点的核心装置，搭配少量输入与输出。

### 方法分层

适合方法论框架、能力栈和内容系统层级。使用可搭建、可搬运的层叠物件，角色参与组装。

### 地图路线

适合用户路径、学习路线和内容承接路径。用连续路线连接少量节点，角色负责入口、推进和反馈。

### 小漫画分镜

适合真实过程、失败转向和使用前后变化。把 2–4 个场景拆成 2–4 张独立配图，每张只表达一个动作并分别执行实例计数；不要在单张图中复制同一固定角色。

### 横向目录

适合长文阅读总览。使用低矮连续装置承载 3–5 个阶段，阅读方向从左到右，完整轮廓宽高比至少约 2:1。

## 原创隐喻三步

1. 把抽象概念转换为物理动作：卡住、漏掉、变重、分拣、沉淀、发酵、开门、折叠、拆包、回流。
2. 选择 1–2 个低科技物件：纸箱、抽屉、漏斗、秤、邮筒、门、水管、线团、闸门、转盘、打孔器、压面机、晾衣绳、工作台。
3. 分配角色动作：从 IP 档案中每个角色的“动作职责”里挑选，让动作改变装置状态。人物常负责拉、推、转动、分拣、标记、递送；伙伴常负责压住、顶住、叼取、搬运、提示——以档案为准，不要给伙伴分配它身体做不到的动作（例如没有手的伙伴去抓握）。

隐喻由当前段落的动作与结构共同决定。每次从正文重新组合物理动作、核心物件和角色职责。移除角色后若隐喻仍完整成立，应重新分配职责，让动作参与输入、转换、阻塞、输出或反馈。

## 构图规格卡

为每张图填写：

```text
主体轮廓：
主体宽度：
视觉中心：
装置尺度模式：高装置 / 低矮横向装置
人物占画布高度：
装置尺度指标：
超大物件锚点：
阅读方向：
留白用途：
各角色位置与动作：
中文标注：
构图风险：
```

普通场景默认主体宽度 65%–78%，水平中心 45%–55%。常规图人物高度占画布 24%–32%；目录图或低矮横向装置图占 22%–32%；任何人物不得超过 35%，且全身必须可测。
