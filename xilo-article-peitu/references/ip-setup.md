# IP 档案：首次登记与更新

本 Skill 不附带任何角色。首次运行时，引导用户把自己的 IP 登记成档案，之后每次配图都从档案读取。

档案目录 `<ip-dir>`：`$XILO_ARTICLE_PEITU_IP_DIR`，未设置时为 `~/.config/xilo-article-peitu/`。

```text
<ip-dir>/
├── ip-profile.md          # 由 templates/ip-profile.template.md 填写而成
├── references/            # 每个角色一张参考图（三视图最佳）
├── stroke-reference.png   # 可选：笔触细节参考
├── header-scale-reference.png  # 可选：首图人物尺寸参考（第一张合格首图可回填）
└── stamp.png              # 可选：首图印章
```

## 首次登记对话

一次性向用户说明需要什么，允许分几轮补齐。必需项只有前两项。

1. **角色参考图（必需）**：每个角色一张清晰图片，三视图（正/侧/背）最好，单张全身正面也可以。支持 1–4 个角色，人物与伙伴（宠物、吉祥物、道具精灵）都算角色。
2. **每个角色的一句话介绍（必需）**：名字或代号、人物还是伙伴、和谁是搭档。
3. 首图刊头文字（可选）：例如栏目名、公众号名。未提供时首图不显示刊头，只保留年月。
4. 印章图片（可选）：首图右下角的落款印章。未提供则不加印章。
5. 色板（可选）：未提供时使用 `style-dna.md` 的默认绿系。用户的角色主色明显不是绿色时，建议从参考图取色生成一套同结构色板，并让用户确认。
6. 默认配图目录（可选）。

用户手上没有现成 IP 时，可以提出帮忙设计：先用文字确定角色设定，再生成三视图，用户确认后作为参考图登记。不得未经确认就把生成结果写进档案。

用户提供的参考图可能包含他人版权角色。只按用户声明登记，不替用户判断授权；如果明显是知名商业角色，提醒用户自行确认使用权后再继续。

## 从参考图提炼档案

逐张以原始分辨率打开参考图，为每个角色写出：

- **身份标志**：最能唯一识别该角色、用于计数的 1–2 个特征（例如“头顶一朵五瓣小花”“胸前星形徽章”）。计数审校以它为准，不只看发色或衣色。
- **外形描述**：发型发色、脸部、服装分层、鞋、配件；伙伴写清身体形状、肢体数量、配色部位。用一段可直接放进提示词的英文，另附中文要点。
- **眼睛规格**：形状、瞳色、是否有高光。参考图里没有高光就写“no highlight”，这是最容易漂移的部位。
- **比例**：人物头身比（发顶至下巴为一头，头部饰物不计入）；伙伴与搭档人物的高度比。看不准时用像素测量并记录。
- **固定色**：角色服装、标志部位使用的颜色（十六进制），与色板的锚点色对齐。
- **动作职责**：3–7 个适合该角色的动作动词，正文配图按这些动作分工。
- **禁止项**：常见错误画法（例如“不要画成发夹”“不要长出手脚”）。

把提炼结果按 `templates/ip-profile.template.md` 填好，**先完整展示给用户确认**，确认后再写入 `<ip-dir>/ip-profile.md`，并把参考图复制到 `<ip-dir>/references/`（保留原图，不改动用户文件）。文件写入后回读一次，确认路径都存在。

## 更新档案

- 修改前把旧档案复制为 `ip-profile.<YYYYMMDD-HHMMSS>.bak.md`。
- 新增或替换角色时只改相关段落，并检查“正文默认出场”和“首图默认出场”是否仍然成立。
- 用户只是在某篇文章里临时换造型时，写进该文章的 shot list，不改档案。

## 首图尺寸参考

档案没有首图尺寸参考图时，首图按 `date-header.md` 的数值规格（头高 280–340px）执行。用户第一次确认满意的首图 PNG，可征得同意后复制为 `<ip-dir>/header-scale-reference.png`，后续首图以它校准人物存在感。
